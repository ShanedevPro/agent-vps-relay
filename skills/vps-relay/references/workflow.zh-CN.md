# 工作流程

## 先了解环境

只询问无法检查得到的目标、设备、预算和服务商偏好。区分 Agent 运行主机、用户客户端和 VPS。
检查系统/架构、权限、工具、IPv4/IPv6，以及 Agent 的实际联网来源：直连、路由器、系统 VPN、应用代理或环境代理。
一个 Google 请求成功不能证明 Agent 的控制通道可用。没有起始可用连接时，需要先由用户提供可信联网/离线安装途径。
提出具体方案并对齐，保留原节点、客户端、规则和代理设置。

## 第一次使用：补齐必要软件

检查 Python、OpenSSH、curl、系统证书和客户端，优先复用已有兼容版本。
有缺失或需要首次启动时，阅读 [首次安装](bootstrap.md)。
缺少 Python 时先按官方平台方法安装，再调用本项目 CLI。不要为了旧示例而强装 Node.js、WSL、浏览器自动化或付费客户端。
按 [客户端说明](clients.md) 从官方发布源核对系统、架构、版本和摘要；登录/付款/管理员及 VPN 权限由用户在原界面完成。
先用便携核心进行隔离测试，不启用系统代理、TUN、DNS 接管、自动连接或开机接管。
安装或首次启动可能改网络时也适用回滚关卡；权限或可靠回滚不足时，只准备用户操作步骤并核实结果。

## VPS 与部署

有合适服务器就复用；需要购买再读 [服务商说明](providers.md)，查询当前方案/流量/IPv6可用性，不硬编码历史价格。
不要索要聊天中的密码、验证码；用户完成登录、付款和验证。先独立核实主机指纹、密钥 SSH、非 root sudo 和控制台恢复。
管理用 Tailscale 不应顺便变成出口节点、接管 DNS 或发布子网路由。

默认 REALITY + Vision/TCP443 与 Hysteria2/UDP443。CLI 的自动服务器路径是 Debian13/amd64；其他环境按 [适配说明](adaptation.md) 自行查官方资料、提出方案并标记实验性。
私有配置留在 Git 外。先审阅 `plan`，再用对应摘要 `apply`。固定上游版本/摘要，不静默升级。
凭据只生成一次；中断后复用本地状态和服务器 receipt，不重置。
REALITY target/SNI 必须验证兼容性；一次失败不等于整个 IP 被封。Hysteria 自签证书必须有实际执行的 pin/CA 校验，并测试错误 pin 被拒绝。

## 隔离测试与客户端

测试核心只监听回环地址，关闭 TUN/DNS 接管。需要时绑定发现的物理接口，不写死网卡名。
只测试实际可用的地址族，IPv6 可选；核实流量没有借旧 VPN 绕行。用物理出口/源地址检查或两端抓包记录新鲜证据。
CLI 接收的是路径验证声明，不能把声明文件伪造为真实观察。
分别测试 HTTP/出口、UDP DNS、错误凭据/证书、重启、小额下载和短时持续连接。
真实客户端和浏览器另验；curl 通过不是浏览器验收或长期稳定保证。一种协议失败时明确部分结果。

把新节点作为独立配置导入，不覆盖、不自动选择旧配置。保存原配置/启用状态、系统代理与 DNS 及本地恢复动作。
用户明确需要独享静态 ISP 出口时，在基础 relay 可用后阅读 [可选章节](static-isp-exit.md)，保留已有路径；阅读指南不构成购买授权。
内置 Mihomo 适配器仅切换已有分组节点，不能冒充跨 VPN 应用的系统恢复。

## Agent 断网时也能恢复

先读 [连续性说明](continuity.md)。恢复命令必须本地可用、非交互、有超时，并声明不可变依赖。
用 OS 托管任务实际执行无人值守恢复，不能只看到“任务已创建”。保存离线恢复卡。
证明失败则不自动接管网络。用户明确同意试切换后，紧邻切换建立默认180秒租约，不自动延长。
Agent/调用进程退出、请求超时、没有提交时，worker 必须自行恢复，不依赖新密码、弹窗、下载或模型回复。
切换后验证真实客户端，再等 Agent 新的一次回复，在单独动作中提交短期 token。
不要把切换、验证、提交塞进同一个脚本。网站能打开但 Agent 不回来时，仍然回滚。
恢复网络不代表自动重启 Codex；重新打开后按 checkpoint 继续，不重复购买、初始化或轮换凭据。

## 管理限制、维护与清理

本机客户端回滚和服务器防火墙回滚分别管理。Tailscale SSH/sudo 和控制台恢复通过前保留公网 SSH。
先建立服务器独立回滚，再限制 SSH；按服务器实际分配的公网地址族从直连来源测试，不能绕服务器自己的代理来测试端口关闭。
额外的服务商 NAT/浮动公网地址填入 `management.public_addresses`。不要求服务器没有的地址族。
两种代理及私网 SSH 复验通过后才提交；TCP443/UDP443 与 Tailscale 传输继续可用。已有地址族无法验证时另找测试路径，不伪造关卡。

按 [维护说明](maintenance.md) 记录正常路由、证书/pin 更新、恢复命令。验收后取消精确任务，按所有权清理临时文件，保留凭据、备份、文档和必要证据。
旧 VPS 的节点、Tailscale、云端实例/快照/磁盘/IP 仅在单独批准后清理；停止不等于释放，删除不会抹掉已发生费用。
公开报告只导出字段白名单，先预览。不得自动上传原始日志、截图、抓包、身份信息或私有状态。
